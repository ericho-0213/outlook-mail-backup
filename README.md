# Outlook 圖檢異常郵件自動備份與清單同步系統

本專案用於自動擷取 Outlook 寄件備份中主旨包含「圖檢異常」之信件，另存實體 `.msg` 檔案，自動解析內文 `[Issue]` 與 `[會議決議]`，並彙整產出具備直接開啟超連結之 Excel 總表。

## 📌 系統功能
1. **雙信箱支援**：歷史封存檔（`2026.pst`）與日常信箱（`archive.pst`）。
2. **自動產出與維護 Excel / CSV 彙整表**：自動增量匯入新郵件並即時更新清單總表（`.xlsx` 與 `.csv`），內建時間遞增排序、文字靠上自動換行、格線美化與欄寬最適化。
3. **5 大標準欄位**：寄件時間、主旨、`[Issue]`、`[會議決議]`、點擊可直接開啟原生 `.msg` 實體郵件之超連結。
4. **每日自動同步**：每日下午 16:00:00 由 Windows 工作排程器背景自動執行，增量補入新信件並跳出桌面通知。
5. **系統全域規則**：已將「腳本路徑動態化準則」寫入系統規範，所有未來專案一體適用。

## 🛠️ 執行環境
- Windows 10/11
- PowerShell 5.1+
- Microsoft Outlook (本機 MAPI)
